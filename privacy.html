SI-US 엔지니어링 단위변환기(이하 '앱', 안드로이드 패키지 이름 io.github.kkarare.twa)는 사용자의 개인정보를 소중히 여기며 관련 법령을 준수합니다. 본 방침은 앱이 어떤 정보를 다루는지 설명합니다.

1. 수집하는 개인정보 항목

본 앱은 이름, 전화번호, 이메일, 위치 정보, 기기 식별자, 광고 ID 등 어떠한 개인정보도 수집하거나 개발자 서버 또는 제3자에게 전송하지 않습니다. 계정 가입이나 로그인도 없습니다.

2. 기기 안에만 저장되는 정보

즐겨찾기, 최근 변환 기록, 마지막 입력 상태, 화면 밝기(어두운/밝은 화면) 설정은 사용자의 기기(브라우저 로컬 저장소) 안에만 저장되며, 외부로 전송되지 않습니다. 앱 데이터를 지우거나 앱을 삭제하면 함께 사라집니다.

3. 웹 화면 불러오기

본 앱은 웹 화면(https://kkarare.github.io/unit-converter/)을 불러와 보여 주는 방식으로 동작합니다. 화면을 불러올 때 GitHub Pages(GitHub, Inc.)가 일반적인 웹 서버 기록(예: IP 주소, 접속 시각)을 자체 정책에 따라 처리할 수 있습니다. 개발자는 이 기록에 접근하거나 이를 수집하지 않습니다. 앱에는 광고, 분석, 추적 도구가 없습니다.

4. 기기 권한

본 앱은 카메라, 위치, 연락처, 마이크, 저장소 등 어떠한 위험 권한도 요구하지 않습니다.

5. 아동

본 앱은 개인정보를 수집하지 않으므로 연령과 관계없이 안전하게 사용할 수 있습니다.
